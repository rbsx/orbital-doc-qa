# Deal pack: 100 Bishopsgate

Three documents about the same property, for demoing the cross-document conflict
check. Upload them into one conversation in this order so they get the labels below.

| Label | File | What it is |
|---|---|---|
| D1 | `01-commercial-lease-100-bishopsgate.pdf` | The existing sample lease of Floors 8–10 (copied unchanged) |
| D2 | `02-report-on-title-100-bishopsgate.pdf` | Report on title for the freehold, with the register entries |
| D3 | `03-measured-survey-100-bishopsgate.pdf` | Measured survey and condition report for Floors 8–10 |

D2 and D3 are generated by `scripts/generate-deal-pack.py`. Everything in them is kept
consistent with the lease (address, floors, tenant, lease date and term, rent, the
surveyors named in the lease) except for these planted conflicts:

1. **Landlord is not the registered proprietor** (D1 vs D2). The lease is granted by
   *Bishopsgate Property Holdings Limited (Company No. 05198234)* (D1 p.3). The register
   shows the freehold owned by *Bishopsgate Nominees (No. 2) Limited (Co. Regn. No.
   11873402)* (D2 p.2 summary, p.3 proprietorship register). Same address, different
   company: who actually granted the lease, and can they?
2. **Restrictive covenant forbids the permitted use** (D1 vs D2). The lease lets Floors
   8, 9 and 10 for Class E(g)(i) office use (D1 p.3 definitions, p.6 clause 6.1). A 1998
   covenant on the charges register bars using any part of the building *above the
   seventh floor* for anything other than a hotel or serviced apartments, Class C1
   (D2 p.3).
3. **Floor area doesn't match** (D1 vs D3). The lease states an aggregate net internal
   area of approximately 32,500 sq ft (3,019 sq m) (D1 p.4 clause 2.2). The measured
   survey, carried out for the landlord before the letting, found 29,850 sq ft
   (2,773 sq m) (D3 p.3), about 8% less. The rent and the 18.7% service charge share
   are based on the area.

Regenerate with (from the repo root, PyMuPDF comes with the backend image):

```sh
docker compose run --rm --no-deps \
    -v "$PWD/scripts:/app/scripts" -v "$PWD/sample-docs:/app/sample-docs" \
    backend uv run python scripts/generate-deal-pack.py
```
